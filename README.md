# مخزن الخليل — تطبيق الأسعار

تطبيق ويب (PWA) لإدارة أصناف محل جملة وأسعارها: مجموعات وفرعيات، بطاقات أصناف بثلاث عملات، تعديل أسعار سريع، ومشاركة قوائم الأسعار عبر واتساب وExcel.

## التقنية
- واجهة: HTML + CSS + JavaScript بدون framework
- قاعدة البيانات والدخول: Supabase (مشروع `khalil-prices`)
- الاستضافة: GitHub Pages / Netlify

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة |
| `css/app.css` | التنسيق (B — كحلي وعنبري) والوضع الليلي |
| `js/config.js` | رابط Supabase والمفتاح العام |
| `js/app.js` | منطق التطبيق |
| `manifest.json` | إعدادات التثبيت كتطبيق |
